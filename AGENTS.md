# Mods for games that provide DualSense support

Follow the [Contributing Guide](CONTRIBUTING.md) or use the specific skill.

- Dependencies and build are managed by [lux](https://lux.lumen-labs.org). To add dependency use `lx add <dependency> -p <package>` command. To check the scripts run `lx check` from the repo root. To run tests use `lx test -p <package>` with the `package` name from its `lux.toml`. Details and pitfalls: the `lua` skill.
