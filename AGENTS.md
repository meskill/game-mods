# Mods for games that provide DualSense support

Follow the [Contributing Guide](CONTRIBUTING.md) or use the specific skill.

- Dependencies and build are managed by [lux](https://lux.lumen-labs.org). To add dependency use `lux add <package>` command. To check the script use `lx check -p <package>`. To run tests use `lx test -p <package>`.
